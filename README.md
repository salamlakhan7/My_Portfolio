# Abdul Salam Portfolio

Interactive static portfolio website for **Abdul Salam** (Backend Developer - Python/Django).

## Preview
A modern single-page portfolio with:
- Responsive hero and contact actions
- Interactive project filtering
- Theme toggle (dark/light)
- Copy email/phone buttons, CV download, and back-to-top action

### Quick Preview (Local)
```bash
python -m http.server 4173
```
Open in browser: **http://localhost:4173**

## Features
- Professional summary and direct contact section
- Skill matrix and education section
- Academic projects with contributions + live and GitHub links
- Certificates and soft skills with icons
- Working interactions: theme toggle, section nav links, project filtering, copy buttons, CV download, back-to-top, and scroll reveal effects
